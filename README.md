Click this link to open NeptuneOS: https://muhammedhaseeb920.github.io/NeptuneOS/

## Quick Start
Open the live demo link above to launch NeptuneOS in your browser.

## Features
* **Clock app:** A clock app featuring a stopwatch!
* **Calculator:** A calculator supporting standard calculations and a history showing previous calculations.
* **Notepad:** Notepad application to write down important information or anything to remember with history.
* **Other:** draggable, closable windows, and a cool dock with colorful app icons!

## How to run locally
1. Clone the repository: git clone https://muhammedhaseeb920.github.io/NeptuneOS/
2. Navigate into the project directory: cd NeptuneOS
3. Open index.html in your browser
